# ADR-0024 — Audience Bridge, architectures narratives, rétention du script, multi-plateforme

- Statut : Accepté
- Date : 2026-11-15

## Décision

1. **Niveaux** (`levels@1`) : un script vise DISCOVERY, EXPLORATION ou EXPERTISE ; une
   **variante** d'un sujet à un autre niveau est un script relié (`level_of`). Chaque niveau a
   ses contrôles :
   - DISCOVERY : jargon expliqué, phrases ≤ 18 mots, format court, accroche immédiate ;
   - EXPLORATION : au moins 2 références, jargon majoritairement expliqué ;
   - EXPERTISE : au moins 3 citations vérifiées, contre-preuves discutées, théories annoncées.

   **Exactitude identique** à tous les niveaux : même Fact Checker, même veto.
2. **Bibliothèque créative** (`architectures@1`) :
   - 9 techniques (accroche, rétention, transition, révélation, conclusion), chacune avec son
     principe, son usage et ce qu'il faut éviter ;
   - 6 architectures : enquête, chronologie, questions de la communauté, portrait, débat,
     comparatif.

   Uniquement des principes rédigés pour Primestone : aucune expression, aucun script ni
   aucune séquence d'un autre créateur. Plusieurs plans par sujet ; les faits vérifiés y sont
   placés mot pour mot.
3. **Rétention du script** (`script-retention@1`) :
   - longueurs (plus de 3 min), transitions faibles, répétitions, moments de révélation,
     moments visuels (montrer la case citée) : ce sont des **hypothèses** ;
   - si une courbe réelle existe (phase 14), les **décrochages observés** sont rattachés à
     leur section.
4. **Motion Studio, contrat 1.1** (compatible 1.0) : `intents` par section (rôle narratif,
   moments visuels, rythme).
5. **Multi-plateforme** : YouTube Shorts, publication communautaire (un fait sourcé et une
   question, aucune réponse automatique), podcast et dossier écrit s'ajoutent aux
   déclinaisons de la phase 9. L'adaptation FR/EN reste une réécriture à part entière
   (`primestone-script adapt`), jamais une traduction mécanique.

## Conséquences

- Les contrôles de niveau sont des heuristiques explicables, à confirmer par relecture.
